# HarvestVision

A small computer vision project for detecting and tracking fruit in orchard environments.

The project currently focuses on:

* Fruit detection with YOLO
* Image/video processing with OpenCV
* Object tracking and counting
* Simple evaluation of detection failures

## Stack

* Python
* PyTorch
* Ultralytics YOLO
* OpenCV

## Goal

Build a clean CV pipeline:

`image/video → detection → tracking → fruit count`
